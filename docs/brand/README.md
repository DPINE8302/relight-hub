# RE;light identity kit

Open `index.html` (or `RElight_Brand_Guide.html` in the source folder) for the visual guide.
Published guide: https://dpine8302.github.io/relight-hub/brand/

## Start here

- Logos: `logo/relight-wordmark-dark-outlined.svg` on light; `logo/relight-wordmark-light-outlined.svg` on dark. These vector masters contain paths, so no font installation is needed. Matching 2400 px transparent PNGs are included.
- Compact mark: `logo/relight-mark-path-approved.png`. Keep this exact approved doorway-and-path mark.
- Artwork: `illustrations/relight-future-path-selected.png`.
- Fonts: `downloads/RElight-Font-Pack.zip`. Official LINE Seed Sans TH Regular, Bold and ExtraBold; desktop TTF and web WOFF2, with the SIL Open Font License.
- Colors: navy #070B17, ivory #F8F6F0, gold #F2C978. Supporting colors and reusable typography/spacing roles are in `tokens.css`.

## Fonts

Unzip the font pack. On macOS, open the TTF files and choose Install in Font Book. On Windows, select the TTF files and choose Install. Restart the design or editing app if fonts do not appear. Use WOFF2 for websites, not desktop installation. Fonts are unmodified copies from LY Corporation's official package: https://seed.line.me/src/images/fonts/LINE_Seed_Sans_TH.zip (accessed 13 October 2026).

Use Regular 400 for reading, Bold 700 for headings and ExtraBold 800 for display. Thai letter spacing should stay at 0; allow vertical room for vowels and tone marks. The Latin example in the guide illustrates the typeface, not a replacement for the locked Thai message: พรุ่งนี้ดีได้ เพราะฉันเลือกเอง.

## Across the project

Film: use the outlined wordmark for title/end slates. Keep subtitles ivory on a dark backing, still during reading, and test at the real projector distance. Do not recolor narrative footage to match the brand palette.
Graphics: one focal point, generous clear space, exact proportions. Use vector logos at any size. Check raster artwork resolution at its final print size. RGB/hex masters require printer-profile conversion and a physical proof; no universal CMYK match is claimed.
Web: navy text on ivory; ivory or gold on navy. Body 16–18 px, line height 1.65–1.8. Blue #0F7598 supports links and focus on light surfaces. Gold and deep gold are not small text colors on ivory.
Games: retain a game's own title and artwork, with the parent palette and type roles in menus, loading and credits. `logo/skyfront-game-logo.png` is the independent Skyfront edition; it does not replace the RE;light parent mark.

The four application studies in the guide show compositional directions, not released film/game screens. Original editable live-text SVGs remain available under their original filenames. For production use, choose outlined masters or PNGs.

## Keep it recognizable

Keep the gold semicolon. Leave clear space at least equal to the lowercase “l” height. Never stretch, shadow, outline or redraw the supplied mark. The illustration is not a replacement for the wordmark. Rejected archived marks are excluded from the kit.

# RE;light identity kit

This is the project-wide identity reference, consolidated from the active RE;light Education visual system and the Hub's documented design tokens. It makes those existing choices reusable across project materials.

## Files

- `index.html` — visual guide, opens locally in a browser.
- `logo/relight-wordmark-dark.svg` — dark wordmark for light surfaces.
- `logo/relight-wordmark-light.svg` — ivory wordmark for dark surfaces.
- `logo/relight-mark-path-approved.png` — user-approved doorway with the winding path inside, exact supplied PNG.
- `illustrations/relight-future-path-selected.png` — your selected illustration, used in the Education homepage hero.
- `tokens.css` — reusable CSS custom properties and font stack.

## Identity rules

- Display the brand as **RE;light**. Keep the semicolon and color it soft gold.
- Use the supplied dark or light wordmark; do not recolor the semicolon independently.
- Use the approved doorway-and-path mark only when the full wordmark will not fit, such as app icons and avatars. Do not use the empty arch, gold-dot-only doorway, or winged game adaptation.
- Use the selected arch-and-path illustration as a feature visual, not as a replacement wordmark.
- Use LINE Seed Sans TH for Thai and Latin text where available; use the supplied system fallback stack elsewhere.
- Core palette: deep navy, ivory/cream, and soft gold. Education blue is a supporting link and focus color on light surfaces.

The SVG logos use live text so they stay editable and small. Their appearance depends on the font stack in the viewer; for print production or a locked logo master, outline the text in a vector editor after confirming the chosen font is installed.

## Relight Skyfront game edition

Use the approved doorway-and-path mark with the canonical RE;light wordmark and SKYFRONT game title. The game name is Relight Skyfront. Keep the parent palette and Thai typography; use cinematic navy surfaces, gold launch emphasis, and blue holographic environmental art. Do not generate a replacement mark from rejected variants.

`logo/skyfront-game-logo.png` is the independent generated game-edition master: SKYFRONT with an aviation insignia, sharing palette and finish rather than the doorway geometry. Use it beside the approved parent identity; do not replace the parent mark with it.

Windows 11 · ARM64 และ x64

Windows x64 Windows ARM64
รุ่นทดลอง · .exe · ยังไม่ได้ลงลายเซ็น
เลือกเวอร์ชันและตรวจสอบก่อนติดตั้ง

คอมพิวเตอร์ Intel / AMD ใช้ x64 ส่วน Windows on ARM ใช้ ARM64 ติดตั้งสำหรับผู้ใช้ปัจจุบัน ไม่ต้องใช้สิทธิ์ผู้ดูแลระบบ

รุ่น ARM64 ผ่านการทดสอบติดตั้ง เปิดโปรเจกต์ และเล่นสื่อบน Windows 11 ตามบันทึกของรุ่น ส่วน x64 ทดสอบเปิดผ่านระบบจำลองบน ARM64 เท่านั้น การทดสอบอุปกรณ์เสียง ปุ่ม HID และโปรเจกเตอร์ยังไม่ครบ

ตรวจสอบ SHA-256 บนหน้า Release ก่อนอนุญาตเปิดไฟล์ผ่าน SmartScreen รุ่นนี้ยังไม่ใช่รุ่นพร้อมใช้งานนิทรรศการที่ผ่านการรับรองทุกอุปกรณ์

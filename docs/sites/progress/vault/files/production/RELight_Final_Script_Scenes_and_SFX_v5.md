**ภาพ:** ดำสนิทที่เข้ารหัสจริงต่อเนื่องจนถึงเฟรมสุดท้าย ไม่มีโลโก้หรือข้อความ  
**เสียง:** **ดิจิทัลไซเลนซ์จริง** ตลอด 72 เฟรม ไม่มีเสียงโทรศัพท์ ไม่มีเสียงแม่ ไม่มีคำตอบผู้ชม และไม่มีดนตรีค้าง

## ข้อกำหนดเสียงและการเล่นจบ

1. **เส้นเสียงหลัก:** ดินสอนำภาพ → เสียงแม่ใกล้ตัว → ช่วงโทรศัพท์จริงที่ภาพยนตร์หยุด → หน้าต่างและอากาศเมือง → เสียงกิจกรรมในชีวิตที่เป็นไปได้ → พัดลม/เพื่อนในโรงเรียน → จังหวะเอื้อมซ้ำ → กิจกรรมสะดุด/ลมหายใจ → ดำก่อนโรงพยาบาล → เสียงหมอ → คำตอบจริงของผู้ชม *ครั้งเดียวใน H02* หรือ `DREAM-00` → เสียงสถานที่ย้อนกลับ → ลมหายใจตื่น → เงียบสนิท
2. **มิติเสียง:** ห้องวัยเด็กใกล้และอุ่น; ฉากความเป็นไปได้เปิดกว้างตามสถานที่; โรงเรียนค่อยแคบลงจากเสียงพัดลมและจังหวะมือที่ซ้ำ ไม่ใช้เสียงสยองฉับพลัน; โรงพยาบาลอู้เพียงตามการรับรู้ของคนครึ่งหลับครึ่งตื่น ก่อนเปิดเสียงคำตอบให้ฟังรู้เรื่องโดยไม่กระโดดดัง
3. **การส่งออก:** ภาพยนตร์ต้องเป็นสองเซกเมนต์ที่ต่อเรื่องครบ 2,880 เฟรม ไม่อบเวลารอโทรศัพท์เป็นจำนวนเฟรมตายตัวในไฟล์ภาพยนตร์ ทดสอบ `DREAM-01` และ `DREAM-00` กับภาพเวลาเดียวกัน ตรวจว่าคำพูดแม่และหมอพอดีเวลา การอ่าน FACT-01/FACT-02 ชัดบนผนังฉาย และ B00 เป็นดำ/เงียบจริง
4. **หลังเฟรมสุดท้าย:** ไฟทางออกของห้องจริงทำงานตามคิวความปลอดภัยหลังภาพดำจบ ไม่มีบทส่งท้ายผ่านโทรศัพท์หรือเสียงบรรยายต่อจากภาพยนตร์ ลบไฟล์เสียงผู้ชมเมื่อจบ/รีเซ็ตตามระบบที่ผ่านการตรวจแล้ว; ถ้าลบไม่สำเร็จต้องล็อกการเริ่มรอบถัดไป

**จุดอนุมัติก่อนจัดแสดง:** ข้อความสุขภาพสองบรรทัดและบทหมอต้องผ่านผู้เชี่ยวชาญ; ภาพอุปกรณ์กับนักเรียนต้องผ่านการตรวจการนำเสนอ; การบันทึกเสียงจริงต้องมีผู้ควบคุมข้อมูล/ช่องทางติดต่อ ขั้นตอนผู้เยาว์ สิทธิเลือกปฏิเสธ การลบ และการทดสอบโทรศัพท์จริงครบก่อนเปิดใช้ หากยังไม่ผ่าน ให้แสดงฉบับ `DREAM-00` เท่านั้น

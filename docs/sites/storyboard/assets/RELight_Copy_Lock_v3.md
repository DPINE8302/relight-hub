# RE:Light — Copy Lock v3

**Authority:** this is the only editable source for spoken or visible production copy.  
**Rule:** shot lists, prompt cards, storyboards, subtitles, and Resolve graphics reference these IDs; they do not create alternate wording.  
**Review status:** creative lock; health/academic, privacy, and legal review still required where marked.

## Status vocabulary

- **Creative locked:** wording may change only through an explicit creative revision.
- **Health review required:** not public-ready until the named health/academic adviser approves it.
- **Dynamic:** visitor-supplied content; never fabricated and used only when the approved recording flow succeeds.
- **PDPA/legal review required:** blocked until the named reviewer approves the notice, consent/decline path, controller identity, and handling rules.
- **Attribution verification required:** wording is stable, but partner marks/service details must be reconfirmed before fabrication.
- **Retired:** preserved only to prevent accidental reuse; never record, display, or submit for approval.

### Recording decision rules

- Decline, silence, inaudible input, microphone failure, missing consent, or an ineligible minor-consent state always selects `CL-DYNAMIC-DREAM-00`.
- The system never fabricates, substitutes, transcribes, uploads, or retains a dream beyond the active experience.
- The venue/data controller must approve the guardian-consent and age-handling procedure before recording any minor. If that procedure is not operationally approved, run the experience in silent-visitor mode.
- If deletion/reset fails, block the next recording session, alert the operator, and complete secure cleanup before another visitor enters.

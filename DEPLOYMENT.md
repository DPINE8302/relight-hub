# Hosting and downloads

GitHub Pages serves `docs/` from the `main` branch. Public repository: DPINE8302/relight-hub. No Vercel deployment is used for this portal, mirrored static websites or games.

Release v2.1.1 contains the native Mac DMG and downloadable static website ZIPs. The Windows release `windows-v2.2.0-alpha.1` contains the ARM64 and x64 `RELight Native` installers. `SHA256SUMS.txt` records hashes of the exact application and website files. Education's ZIP is source and requires its existing server/database; it is not a static/offline export.

The source application DMG and Windows installers are copied/uploaded byte-for-byte. The Windows installers are unsigned and install per-user. Public packages exclude credentials, private funding/identity documents, participant audio and local device settings.

Static game copies use relative assets and hash routes. Original project folders are preserved. Mirrored historical presentation pages are explicitly distinct from current publication approval.

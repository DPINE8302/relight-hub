# RE:Light Hub
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Visitors opening RE:Light websites and games or downloading website packages and the Mac application.
## Product Purpose
One direct directory of project links and downloads. No account required.
## Capabilities and Constraints
Static HTML, CSS and JavaScript on GitHub Pages. Website ZIPs and Mac DMG on GitHub Releases. Education requires its existing backend; its download is explicitly source code. Preserve original project folders.
## Brand Commitments
Inherit the actual Education website CSS, LINE Seed Thai, navy, ivory, cream and gold, RE;light wordmark, navigation and buttons. Text-only hero without a heading image. Project rows with uniform AI-created covers based on each actual project screen; no generic books or unrelated imagery.
## Evidence on Hand
Current project screenshots, published website/game builds, native app screenshot, actual 2.1.1 DMG and validated download packages.
## Product Principles
Make opening websites and downloading packages immediate. No film gallery, document catalogue or extra editorial sections. Teacher Storyboard is excluded from the hub, hosting and downloads at the user’s request.
## Accessibility & Inclusion
Responsive desktop and mobile, semantic links, keyboard focus and clear platform requirements.

# RE:Light Hub
<!-- impeccable:product-schema 1 -->
## Platform
web
## Users
Public visitors who want to explore RE:Light's film, immersive room, games, learning resources, and download the Mac application.
## Product Purpose
One public entry point connecting the project's creative work and installable applications. Anyone can browse and download without an account.
## Capabilities and Constraints
HTML, CSS and JavaScript on GitHub Pages. Public DMG downloads on GitHub Releases. Preserve working originals. Dynamic education/community services remain linked to their existing host. Publish curated creative material, never private financial/identity documents, credentials, recordings or internal device data.
## Brand Commitments
RE:Light identity, Thai-first language, existing cinematic room artwork. User chose film and immersive room as the opening, followed by exploration of all work.
## Evidence on Hand
Existing room visualization, four draft film scenes, native app screenshots and 2.1.1 DMG, PUFF//WORLD build, two web game collections, production documents and print assets.
## Product Principles
Lead with real work. Keep downloads direct and compatible. Identify drafts and historical editions honestly. Provide a searchable catalogue.
## Accessibility & Inclusion
Responsive mobile and desktop layout, semantic controls, keyboard operation and reduced-motion support.

## Updated scope
User explicitly narrowed the hub to website/game links, website ZIP downloads and the Mac application download. No film player, gallery, searchable document catalogue, educational editorial, or additional project storytelling on the hub homepage. Preserve the existing visual identity while making every open/download action immediate.

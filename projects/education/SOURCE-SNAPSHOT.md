# Education source snapshot

Generated from the owning `production/relight-web` application by `node ecosystem/scripts/snapshot-education.mjs`. This is a local release candidate, not a deployment. SOURCE-SNAPSHOT.json records the exact source hashes. Environment files, local databases, dependencies, build caches and linked files are excluded. Existing ignored runtime data stays in place and is never packaged.

Use the owning README and EXHIBITION guide for setup. A server and Postgres are required for shared production features; this is not a static export.
